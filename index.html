How can we help you?

Choose a question below to read a simple answer about the website and its study resources.

CSS PrepHub is an online resource platform for CSS aspirants. It brings together subject-wise past papers, the CSS syllabus, CSS MPT past papers, study notes and recommended books in one organised place.
The CSS past-paper section provides year boxes for 2015 to 2026. A specific paper will open or download only after its PDF file has been added to the website folder using the correct filename.
Open CSS Past Papers, select a compulsory subject or an optional subject from Groups I–VII, and then choose the required year. Use the View PDF button to open the paper or Download to save it.
The CSS MPT Past Papers page has separate boxes for 2022 to 2026. Each paper requires its matching PDF file, named according to the filename used by the website, to be uploaded before it can be viewed or downloaded.
The PDF may not have been uploaded, or its filename may not match the website's expected filename. Place the PDF in the same folder as index.html and check the exact spelling of the filename. The syllabus, notes and books also need their matching PDF files uploaded.
Quick tip: If a resource does not open, first check that the matching PDF is uploaded and that its filename is spelled exactly as expected.
